# 🌤️ Python Weather App

A simple weather application built with Python that fetches real-time weather information for a city.

## Features

- Get current weather information
- Shows temperature
- Shows feels-like temperature
- Shows humidity
- Shows weather condition
- Simple command-line interface

## Technologies

- Python 3
- urllib
- JSON
- API

## How to Run

Run this command:

python weather_app.py

Then enter the name of a city.
